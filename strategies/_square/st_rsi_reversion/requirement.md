# RSI 均值回归(只做多)

在 BTCUSDT 现货上按 1 小时 K 线运行。用简单均值口径(不是 Wilder 平滑)计算 RSI:RSI 低于超卖线时买入,高于超买线时卖出空仓,其余时间保持原有仓位。只做多,不做空,属于均值回归。

## 参数

- RSI 周期(`period`):默认 14
- 超卖线(`oversold`):默认 30.0
- 超买线(`overbought`):默认 70.0
- 目标仓位占权益比例(`target_fraction`):默认 0.2
- 止损比例(`stop_pct`):默认 0.03

## 仓位与风控

- 交易标的:BTCUSDT 现货,1h K 线收盘后决策。
- 持仓以交易所为准:每轮从账户读当前持仓,没有新信号就保持。
- 仓位 = 目标仓位占权益比例 × 真实权益(可用 USDT + 基础币市值);不足最小下单金额时本轮不下单。
- 每次开仓后立即挂保护止损单,止损价 = 开仓参考价 ×(1 ∓ 止损比例)。
- 首轮先用 factor_evaluate 评估核心因子,verdict 为 PASS / PASS_CONDITIONAL / HOLD_INFO 才交易。
- 取数或下单出错时本轮跳过并记录日志,下一轮继续。
