# 因子评估框架审查

本轮完成第一阶段的 **factor evaluation matrix**：在六道裁决闸门之外，统一四种收益目标、14 维证据盘点、时间块不确定性估计和八组离线诊断图。框架既要回答因子“好不好、卡在哪一关”，也要让不可测量或尚未验证的维度显式可见。第二阶段的因子组合、风险预算和策略执行仍为 `NOT_EVALUATED`。

使用入口见 [README](README.md)，完整产物见 [示例报告](factor_eval/examples/report/index.html)。报告可离线浏览，包含矩阵、闸门证据、目标定义和覆盖率、图表及明细，另附可复算的 JSON 与 Markdown 卡片。

## 已确认并修复的裁决与计算问题

| 问题 | 修复后的行为 | 验证位置 |
|---|---|---|
| 必需检查缺失、跳过闸门或结构失败，仍可能给出通过类结论 | 必需 `N/A` 阻止通过；区分缺证、结构失败、稳健性失败和建议项警告 | `tests/eval/test_matrix_audit.py` |
| 缺少持仓数据时，局部可核算周期的盈利可能替代完整净收益 | G3 要求 val/oot 计划周期完整可核算；局部净收益只作诊断 | `test_matrix_audit.py`、`test_engine.py` |
| 有效信号不足被当成免费空仓，零收益进入均值 | 标记 `missing_signal`，完整净收益和 Sharpe 保持未知；已观测常数信号仍可是真实空仓 | `test_engine_audit.py` |
| 自定义分段允许未来 dev 决定过去验证段的方向 | dev 必须最早，val 先于 oot；拒绝重叠和非法边界 | `test_engine_audit.py` |
| 面板只检查对齐，缺日、非法价格、掩码真值转换可能被接受 | 验证 UTC 连续日网格、唯一标的、OHLC/成交量；缺失保留，非法 eligibility 被拒绝 | `test_contract_audit.py` |
| 标定只核对期限和成本，同名池的数据、掩码或时点设置变化不失效 | 绑定全部面板值、缺失值、分段、执行参数和引擎身份；旧标定须重跑 | `test_contract_audit.py` |
| 高 IC 的未来收益正控只能说明度量有效，不能阻止真实泄漏 | 对可重跑函数做多截断点前缀一致性抽查；失败进入 G0，预计算信号的因果性记为未知 | `test_causality_audit.py`、`test_factor_eval.py` |
| 分箱跨样本混读、未来标签缺失改变分组；各期限分别翻号掩盖期限反转 | dev 定箱数、val 读结构，各箱比较共同日期；期限检查使用主期限冻结方向 | `test_structure_audit.py`、`test_matrix_audit.py`、`test_factor_eval.py` |
| 窄截面基线回归耗尽自由度，或数值零残差被重新排序成伪因子 | 按实际矩阵秩判断自由度，退化残差保持不可用；独立残差仍能保留 | `test_matrix_audit.py` |
| 多候选搜索结果和单候选筛选混淆，报告未充分区分阶段 | 输出试验数、数据选择及留出限制；申报多候选时阻止 `PASS*`；组合明确为 `NOT_EVALUATED` | `test_factor_eval.py` |

默认 100 次 AR(1) 随机信号标定已按当前引擎重新生成，记录数值面板和引擎哈希。评分输出保存全部指标、信号、评估代码、可取得的因子源码、标定内容哈希及运行库版本。固定随机信号的 p95 是该生成假设下的参考，不能当成经过反复搜索后的通用显著性门槛。

未知资金费没有补成零；默认样本中的部分完整净收益仍可能不可计算。此时应读作缺证，不能拿可用子样本的好结果通过成本关。前缀审计能发现常见未来 shift、居中滚动和全样本标准化，但不能证明外部状态或上游发布时间已经满足时点约束。

## 本轮补齐的完整矩阵

### 四目标与共同样本

`targets.py` 同时构建以下标签，均使用 `open[t+entry_lag]` 到 `open[t+entry_lag+h]` 的前瞻区间：

| 目标 | 实现 |
|---|---|
| `raw_rtf` | 前瞻 open-to-open 对数收益 |
| `normed_rtf` | 原始收益除以事前同期限历史收益波动率 |
| `res_rtf` | 原始收益减去事前 beta 乘以同持有区间基准收益 |
| `normed_res_rtf` | 残差收益除以事前同期限残差波动率 |

风险估计使用信号形成时已完成的 close 观测，默认 60 个观测、至少 40 个有限值；同期限收益直接估计，没有 `sqrt(h)` 假设。beta、协方差和残差尺度使用相同的历史配对样本。基准明确指定，默认 `BTCUSDT`；缺失、恒定或历史不足时不选择替代基准。

四目标在 dev/val/oot 的主对照共享有效单元，另外保留各自覆盖率、可用样本对照和不可用原因。共同样本为空时，原始目标仍可展示，但四目标比较维度不会被写为已完成。收益目标残差化与 G5 对信号去除公开基线是两种不同检验。

### 不确定性与样本权重

`statistics.py` 分开报告逐日横截面 RankIC/Pearson IC 和 pooled 相关/斜率。IC 默认需要至少五个有限资产对、且截面非常数；pooled 关系给每个日期总权重 1，再在日期内均分，可能包含时间水平效应，不能冒充 IC。有效日期、资产对数及区间各自列出。

默认 bootstrap 100 次、块长度 `max(10, 2*h)` 日，整块携带全部资产，保留缺失日期，四目标同期限对照复用日期抽样，跨期限按各自块长估计。有限日期不足两块长度时不生成 bootstrap 区间。报告还给出 HAC 正态近似区间；bootstrap 为逐点 95% 区间，没有同时置信带或多重检验校正。`target_available` 对照保留自己的点估计与 HAC，不额外重采样。

### 八组诊断图和可复核产物

| 图组 | 本轮实现 |
|---|---|
| 分布、覆盖与 CDF | 有限值、零值、NaN/无穷值统计和信号分布，缺失与真实零值分开 |
| 四目标分箱 | dev 日期等权分位数最多 25 箱，ties 保留，val 四目标共同单元的分箱均值与区间 |
| 过去收益条件切片 | dev 一日已实现收益最多 20 箱，val pooled 相关/斜率及 IC 明细 |
| 期限与延迟曲线 | h=1…60；固定持有长度的入场延迟扫描；原信号、主方向及各曲线共同样本冻结 |
| 时间和状态稳定性 | val 年、季度、星期、事前波动组，以及逐一剔除标的 |
| IC 与交易难度 N | 可选 `spread` 的 `N=同期限事前波动率/完整 log(ask/bid)`；仅统计对应有效 IC 样本的 N 分位数 |
| 对/错极端案例 | dev 冻结 p99.5 信号与 p99 目标阈值，val 最多各六例，去除重叠市场片段并显示时间轨迹 |
| 成本压力 | 同一实际持仓现金流上的 0、0.5、1、1.5、2、3 倍成本；零交易成本仍支付资金费，局部收益单独列示 |

诊断分箱各箱可以使用不同日期，它描述条件均值，不是可交易组合；G2 仍另用共同日期和更严格的每箱标的要求。薄切片不强行产出 IC，极端案例不足时不补足数量。极端案例按未来结果选取，只作事后诊断。日频数据不声称支持日内时段检验。

`--report-dir` 导出八组 PNG、离线 HTML、完整 JSON 和 Markdown。`--bootstrap` 调节重采样次数，`--benchmark` 显式选择基准。`--quick` 只跑六道闸门，不能同时要求完整图表报告；`--bootstrap 0` 则只关闭重采样、保留诊断点估计和可用 HAC。未提供真实价差时 N 图保留 N/A，不用 high-low 代理，也不推断容量。

14 维矩阵覆盖数据、信息、结构、净收益、稳健性、基线重复性、四目标比较、抽样不确定性、期限/延迟、交易难度、容量、搜索选择、封存留出和策略组合。前六维使用闸门裁决；`MEASURED` 仅表示附加诊断存在。容量、封存留出和组合明确留为 `NOT_EVALUATED`，完整盘点不等于全部证据通过。

## 第一阶段仍需补齐的外部证据与扩展

1. **更宽、历史时点一致的标的池与来源审计。** 默认池按快照时点成交额选择，平均每天约 7.7 个合格标的。资格掩码不能消除事后选币偏差，已有逐月前十对照也不能保证覆盖完全消失的历史合约。需要可审计的上市、退市、当时可得流动性及数据发布时间/修订记录，再评估更宽池上的结论。更宽池也能提高 25 箱、条件 IC 和基线残差检验的统计功效。
2. **真正封存的验证流程。** `oot` 是日期分段名称，不能证明研究人员未查看过。需要在研究前登记假设、主期限、方向和门槛，冻结代码与数据清单，保留未用于调参的最终样本并记录开启时间。
3. **完整试验账本与搜索校正。** `trials_seen` 是声明和阻断机制，不会自动发现未申报的试验。仍需记录公式、参数、窗口、方向和失败结果，评估选择偏差；仅在前提满足时使用 DSR、PBO 等方法，并以新样本验证。固定 AR(1) 参考还可补充生成假设敏感性、尾部分位数不确定性，以及多期限/切片的同时推断。
4. **真实报价、成交与容量。** 当前 open 是日频价格代理，不是实际成交或 mid；N 的报价必须由调用方提供，并验证可得时点。现有成本和延迟压力不包含深度、随资金规模变化的冲击、成交参与率或填单概率，也没有净收益置信带。还需量化历史标记价格代理和缺失资金费的影响。固定延迟 N 诊断可在有合格报价后扩展至不同执行时点；容量仍需规模相关的成交实验。

## 进入第二阶段的条件

第一阶段产出可复现的候选档案：信号定义、数据可得性、冻结研究约定、有效样本、信息与成本诊断、失效情景、已知风格重复性及尚缺证据。必需证据不足时保留 `HOLD`，后续组合收益不能替第一阶段补结论。

第二阶段再检验因子之间的相关和互补性、权重拟合、风险暴露、换手净额、组合后的成本与容量，以及独立样本上的组合增量。单因子不赚钱不代表加入组合必然无用，单因子通过也不代表加入组合必然增益；这些需要实际组合实验回答。
