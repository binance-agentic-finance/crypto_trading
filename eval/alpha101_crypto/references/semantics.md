# Alpha101 v2 的来源与算子约定

核查日期：2026-09-10。`paper` 表示原文输入单位配合下列明确的本地算子约定，不能理解为已复现作者的私有实现。

## 原始来源

[Kakushadze, *101 Formulaic Alphas*, arXiv:1601.00991](https://arxiv.org/pdf/1601.00991)，已直接下载并阅读 PDF 第 15—16 页的算子和输入说明。当前下载版本保存在本目录，校验和见 `sources.json`。

| 项目 | 论文明确的内容 | v2 的可重复实现选择 |
|---|---|---|
| `rank` | 横截面排名 | 当前 eligible 池中的升序平均并列秩，除以该行有效观测数；取值 `(0,1]` |
| `ts_rank` | 过去 d 日的时序排名 | 完整窗口中最新观测的升序平均并列秩，除以 d；与横截面秩统一尺度 |
| `ts_argmax/min` | 极值发生在哪一天 | 最老=1、最新=d，出现并列时取最早的一次 |
| `scale(x,a)` | 绝对值之和等于 a，默认 a=1 | 当前 eligible 横截面的 L1 缩放；不去均值、不除标准差 |
| 非整数窗口 | 向下取整 | `floor(d)`，窗口在小时格上仍按 bar 数保留 |
| 线性衰减 | 线性权重归一后加权平均 | 最老权重 1、最新权重 d，需要完整窗口 |
| `returns` | 每日收盘到收盘收益 | 原始收盘价的简单收益 `C_t/C_(t-1)-1`，不填充缺失 |
| `volume` | 标准成交量定义 | 基础币数量，保留合约标的的计量单位 |
| `adv(d)` | 过去 d 日的平均美元成交额 | 独立取 `quote_volume` 的 d 格均值，包含信号时点已完成的当前 bar |
| `vwap` | 当日成交量加权价格 | `quote_volume / base_volume`；base=0 时缺失 |
| `signedpower` | 该 PDF 写为通常幂运算 | 按通常幂运算计算；两处公式的底数均为非负。额外保留缺失，不允许 `1**NaN` 生成有效值 |
| 标准差与协方差 | 移动时序标准差、协方差 | `ddof=1`；零方差相关系数记为缺失 |

原文未明确 rank/ts_rank 的数值尺度、arg-extrema 的方向和并列规则、simple/log 的选择、ddof 以及缺失窗口规则。以上均作为 v2 的明确约定，不称为“论文唯一口径”。统一百分位秩意味着 #88 的两个分支都可能决定最终数值；旧版混合秩尺度的退化不再是结构性必然。

## 公开实现的交叉核查

核查了 [yli188/WorldQuant_alpha101_code 的 101Alpha_code_1.py](https://github.com/yli188/WorldQuant_alpha101_code/blob/master/101Alpha_code_1.py)，读取源文件，没有执行第三方代码；下载内容 SHA256 保存在 `sources.json`。

该实现采用原始时序秩、百分位 `rank`、`argmax+1`，但还存在默认排名轴、以基础量均值代替美元 ADV、缺失前后填充等选择。它可证明公开实现之间存在差异，不能作为原文含义的权威解释。v2 没有复制这些填充和输入替换行为。网页搜索的摘要对 `adv` 和 `scale` 也有不准确解释，因此本模块以 PDF 原文而非搜索摘要为来源。

## 两种输入版本

- `paper`：原始价格、基础币 volume、美元 quote-volume ADV、原始简单收益。原文的 `volume / adv` 因而保留基础数量/美元的量纲差异，没有静默改成相对成交活跃度。
- `normalized`：价格除以滞后 1 格的完整 250 日原始 close 均值；volume 除以滞后的完整 250 日基础币 volume 均值；ADV 源序列为 quote_volume 除以滞后的完整 250 日 quote_volume 均值，再按 d 格求均值。小时格归一化窗口为 6000 根，最低观测数也为 6000。returns 保留原始简单收益。

normalized 是新的 v2 研究对象，与旧版将 volume 和 ADV 都源自归一化 quote_volume 的实现不同。两个版本应分别报告，不能在观察结果后挑选更好的版本作为主结果。

## 缺失、准入与代理输入

全部时序滚动算子需要完整有限窗口，不前填、后填或零填。条件公式要求条件已知，选中分支决定值是否可用；未选中分支无需可用。大小比较、幂运算和 min/max 都显式传播所需操作数的缺失。

每次内部 `rank`、`scale`、`indneutralize` 都按该时点 eligible 掩码执行，最终输出也按 eligible 掩码。原始时序历史保留，因此币种新进入交易池时仍可利用此前已观察到的历史 bar；只有对横截面排名序列做滚动计算时，需要对应历史日期已准入的排名值。

18 条行业相关公式以 eligible 池去均值替代行业/子行业中性；#56 的市值以原始美元成交额 30 格完整均值、滞后 1 格替代。代理因子共 19 条，元数据逐条标记，应与其余 82 条分别报告。这里的 30 格在小时实验中是 30 小时。

原始报价成交额通常以 USDT 计价，作为美元成交额近似；没有另行对稳定币脱锚调整。
