2. 用我們的 blocks 組成策略

新增 strategies/standard/blocks_reference_bots.py —— 一支 TRADE 一支 SELECTION, 指標全部走 canonical blocks,沒有任何手算:

ema_fast = I.ema(close, cfg["ema_fast"])       # indicators
ema_slow = I.ema(close, cfg["ema_slow"])
adx      = I.adx(df, cfg["adx_period"])[0]
atr      = I.atr(df, cfg["atr_period"])
cross_up = C.ma_cross_above(ema_fast, ema_slow)   # conditions
trending = C.adx_trending(adx, cfg["adx_min"])
# selection 側
uni = U.filter_quote_volume(universe_df, cfg["min_quote_volume"])   # universe
uni = U.augment_with_news(uni, rank_df)

為什麼重要:指標走同一個函式庫,回測 / paper / live 才會算出同一個數字 —— 這正是先前 ma_cross_exit 在 live 手寫 EMA 造成三方不一致的根因。

其餘 5 支 v2 策略目前沒走 blocks(funding_* / news_catalyst_trade / social_flow_divergence 都是行內自算)。它們能跑,但少了「同一份算術」這層保證。

3.1 為什麼 v2 比 v1 完整

v1 signal.schema.jsonv2 signal.schema.v2.json
平倉語意只有 side: long/short —— 無法區分「平多」與「開空」 intent:open/add/reduce/close/flip/flat/hold + reduce_only
出場兩個裸欄位 ExitPlan:stop / TP 階梯 / trailing / time_stop,隨訊號走
三種 bottrade / selection 兩套 trade / selection / advisory 同一組 key
產出者每支策略手寫 generate() 框架 StandardBot 產生
機器驗證有 schema,無人使用 從 dataclass 自動生成,11 個 definitions

4. v2 → 既有引擎的橋接

修正前 v2 bot 根本跑不了回測:runner.py 做 float(payload["size"]) —— v2 的 size 是 SizeSpec 物件 → TypeError; 而它讀 payload["exit_spec"],v2 叫 exit_plan → 停損被靜默忽略。

在傳輸邊界加轉譯(不動引擎),v2 dict 原封保留、額外附上引擎要的 key:

{
 "bar_timestamp": 1775462399999,
 "engine_size": 0.47869928871965395,
 "exit_spec": {
  "max_bars": 24,
  "side": "long",
  "atr_at_entry": 721.6398857076825,
  "type": "atr_stop_tp",
  "stop_mult": 2.0,
  "tp_mult": 3.0
 },
 "risk_hints": {
  "target_position": 1
 },
 "target_position": 1
}

額外 key = bar_timestamp, engine_size, exit_spec, risk_hints, target_position。 engine_size 刻意不叫 size —— 覆寫掉會讓 payload 失去 v2 合規性。

4.1 三個「拒絕猜測」的決定

  • QUANTITY / QUOTE_AMOUNT / POSITION_PCT 不換算: 需要帳戶權益或現有部位才算得出來。引擎的預設是 1.0(滿倉),猜錯就是靜默滿倉, 所以設 engine_size=None 並附 size_unresolved 說明。
  • RISK_PCT 只在停損距離可解時換算(公式 risk ÷ stop_distance,上限 1.0)。 市價單若未聲明參考價則拒絕。
  • 分批止盈只保留第一段,並記錄 _dropped_tp_legs —— 沒有任何模擬引擎支援 partial close, 靜默截斷比直說更糟。
