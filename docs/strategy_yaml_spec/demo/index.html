自然語言 → YAML 策略 → 訊號

用伺服器受控的語言模型把一句話轉成交易或選幣 YAML 草稿；交易可回測或產生訊號，選幣可手動輸出候選籃子。非 agent。

1 受控 LLM 轉換

LLM endpoint、model 與選用的 API key 僅能由啟動 demo 的伺服器環境設定；瀏覽器不會傳送或保存它們。自然語言預設不會離開本機，外送仍必須由伺服器在啟動時明確 opt-in。
此步驟只產生 YAML 草稿與靜態結構/意圖檢查；它不是 frozen bundle runtime、語義驗證或可晉升的私有資料收據。
